# simenv — 用例 30~43 本机模拟环境

一条命令重建 SEQUENCE2（用例 30~43）所需的全部外部模拟器。地址在用例消息中
本已是本机形态（127.0.0.1:5020/5021/2404/2405/2406，influx 经 runner PORT_MAP
映射 18086）——本目录提供的是这些地址背后的**服务本体与数据**。

## 用法

```bash
sudo bash setup_simulators.sh
```

- 需 root（modbusd/iec104d 读 license；端口绑定）
- 幂等：重复执行会清理旧进程后重建；机器重启后需重跑
- 前置：本机 `redis-server` 运行中（6379 无认证）、`/usr/local/bin` 下已安装
  `modbusd`/`iec104d`/`redis_tool`、influxd 1.8 二进制（脚本内路径），
  `/var/acquisition/license` 存在

## 数据流与组件

```
redis_tool（写浮点值，8 字节 double + 6 字节时间戳的二进制格式）
  → Redis db0（键名前缀 c4e2e_）
    → modbusd ×2（MGET → DAM → Modbus TCP 从站）
        127.0.0.1:5020  变桨控制器（用例 30/42：10 点浮点，FC3/FC4）
        127.0.0.1:5021  油泵控制器（用例 31：线圈 1 点 + 保持寄存器 7 点）
    → iec104d ×3（IEC104 从站，公共地址 CA）
        127.0.0.1:2404  1号主变 CA=1（用例 34：六点，25601 电度走变化上报）
        127.0.0.1:2405  2号主变 CA=1（用例 35：四点）
        127.0.0.1:2406  3号主变 CA=2（用例 37：四点，与 2号主变同 IOA 跨实例并存）
  → c4_modbus_client / c4_iec104_client 采集 → C4 接入链路

influxd 1.8（127.0.0.1:18086，用例 38~40/43 入库对点；数据由 runner
inject() 注入 shm，不依赖 redis）
```

## 端序定版（关键，2026-10-31 源码仿真 + 探针 18 点实证）

modbusd 浮点写入与 C4 客户端解码链（每寄存器换 → 字交换 → 小端解释）组合后，
可用配置为 **modbusd `{swap: 1, hton_register: 1}`**（即 modbusd 官方示例端序）
↔ agent 实例默认 `{hton_register: 1}` + 点表 `swap: 2`。改为其它组合（如
swap=0）会产生 denormal 值、对点全挂——勿动。
